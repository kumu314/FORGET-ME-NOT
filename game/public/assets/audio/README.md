# 原创程序化音效与来源说明

## 一、当前音效来源与许可证

本目录全部32个 `sfx_*.wav` 由本项目 `tools/generate_original_sfx.py` 的数学波形、固定种子噪声及自编短音型生成。生成器不读取任何外部音频，没有网络请求或第三方采样依赖，也没有使用语音、犬声或其他动物录音。犬叫、犬受伤和Boss吼声均为风格化合成音。

音效按仓库的MIT许可证提供；本目录 `LICENSE.txt` 是仓库根 `LICENSE` 的原文副本。`manifest.json` 将每个加载键、文件名、合成配方、固定种子及WAV SHA256绑定到生成器源文件，另记录生成器和许可证的SHA256。新的32个文件替换此前来源未确认的素材库样本；当前版本及构建输出只使用这些生成文件。本次没有改写仓库历史中的旧版本。

现有 `AudioManager.loadSfx()` 的32个键、`assets/audio/sfx_*.wav` 路径、场景事件和音量总线均保持兼容。雨声仍通过 `audio.playLoop('rain')` 循环，其他音效单次播放；不需要修改音频管理器、UI或关卡接线。

## 三、生成与验证

从仓库根运行，仅需Python标准库，不需要安装依赖：

```sh
python tools/generate_original_sfx.py
python tools/generate_original_sfx.py --check
```

`--check` 在内存重新合成全部32个文件并逐字节比较WAV、manifest和许可证，不覆盖产物；不同内容返回非零退出码。固定种子在manifest中用16位十六进制字符串保存。若需审计读数，添加 `--report D:/CodexOutputs/黑客松/reports/quality-20261108/original-sfx-check.json`。跨Python/libm平台可能出现末位PCM差异，应在目标环境运行核对。

音频规格：单声道、22050Hz、16-bit PCM。合成末端使用短FIR平滑；单次音有6ms起音和18ms收尾，首尾样本为零。雨声使用圆周滤波噪声与周期幅度调制，挑选相邻样本差最小的位置作循环接缝，不通过淡出制造循环断层。

生成器校验削波样本为零、峰值不高于0.781、DC偏移绝对值低于0.01、相邻样本差不高于0.45、循环接缝差不高于0.002；`game/tests/originalSfx.test.js` 还检查加载键全覆盖、来源/许可证哈希、波形电平、文件长度和雨声接缝附近能量。数值范围以满刻度1计。

技术边界：这些读数不等于人耳验收。主观听感、犬声辨识度、连续战斗的音量平衡及设备差异仍需试听；合成犬声不追求录音写实感。

## 四、原创程序化 BGM（issue #24）

三首配乐的完整八小节 MIDI 音高表和配器在 `game/src/audio/scores.js`，由本项目于 2026-11-07 原创编写，Web Audio 实时合成；没有引用、采样或下载第三方音乐。本次32个离线合成音效的替换不改动这三首配乐。

| key / 场景 | 曲名 | 速度 / 循环时长 | 实际配器与节奏 |
| :--- | :--- | :--- | :--- |
| stage1 / 青年 | 操场上的纸飞机 | 144 BPM / 13.33 秒 | 方波短音主旋律、三角波四分音符低音；明亮的 C–Am–F–G 进行，密集八分音符与高八度回句 |
| stage2 / 中年 | 雨夜末班车 | 108 BPM / 17.78 秒 | 锯齿波旋律、650Hz 低通的八分音符八度交替低音、1200Hz 低通长和弦铺底、110→40Hz 正弦底鼓；Am–F–C–G 进行，合成器夜行风格，与场景雨声叠加 |
| stage3 / 老年 | 长椅边的黄昏 | 66 BPM / 29.09 秒 | 正弦波稀疏旋律、慢起音三角波长和弦，C–F–Am–G–C–F–G–C；没有鼓组，较长休止和释放，温暖慢板 |

`startBgm('stage1' | 'stage2' | 'stage3')` 自动切歌；相同 key 不会叠加循环。25ms 定时器预排未来 120ms 的音符，起音使用 AudioContext 时钟；浏览器挂起期间不推进乐谱，恢复时不补播堆积音符。`stopBgm()` 同时停止定时器和已经预排的音源，关卡切换不会留下上一曲的长和弦。
