# UI / 输入 / 遥测集成复核（2026-11-08）

基线 develop dc18488 的只读审计复现：换关后遥测失效；声音滑块漏掉已按下按键的释放；结算时长继续增长；repeat计入按键次数；点击叙事遮罩未快进；同帧升级和彩蛋重叠后提前恢复物理。前五项由本模块修复，暂停归属与转场物理由 StageScene 集成修复。

输入修复在DOM控件获得焦点时重置真实Phaser Key与语义输入；点击声音面板外会释放仍留在面板内的焦点。没有把Phaser原生已处理的窗口blur误报为额外缺陷。转场遮罩点击现在接通既有快进标记。

每次Scene安装新的遥测handle/runId，shutdown清理全部监听与安装标记。结算后elapsed与计数冻结；outcome区分完成/中断；repeat、隐藏页、控件、弹窗与转场期间的输入不计入游戏按下次数。该数字不代表成功攻击、长按时长或玩家打法。墙钟时长仍含阅读、暂停和闲置。

revision由Vite构建自动读取源码SHA，允许VITE_GIT_SHA覆盖；无Git的源码归档仍可构建且明确unknown。contamination标记T、R、物理诊断或显式自动化标记；不能自动识别任意控制台注入。单关download保留，新增history/downloadAll一次导出已存各关与当前关，按runId去重，存储/旧记录缺失时给出warnings。见[真人试玩指南](../playtest-guide.md)。
