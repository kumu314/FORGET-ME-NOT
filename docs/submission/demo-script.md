# 《见我》Until the End · 3 分钟演示脚本（定稿）

> 演示环境：本机浏览器跑 `game/dist`（`npx serve dist` 或任意静态服务器），1280×720 投屏。
> **渲染路径：默认 WebGL 即可**——线上实证（2026-11-08，run 基线 4e75f6b2）：默认参数 fps 60、134 请求零 404、pageerror 0。仅自动化探针（headless Edge）需加 `--disable-webgl`，真实浏览器不需要。
> 在线兜底：https://kumu314.github.io/UNTIL-THE-END/

---

## 一、演示前 3 分钟检查（后台做，不上台）

| 顺序 | 动作 | 通过标准 |
|---|---|---|
| 1 | `cd game && npm ci && npm run build` | 输出 `✓ built in …`，无 error |
| 2 | `npx serve dist`（或任意静态服务器指向 `dist`） | 浏览器能打开首页，**不要直接双击 index.html**（file:// 不行） |
| 3 | 打开游戏，等第一关画面完全亮起（相机淡入结束） | 能看到主角、地面、小怪，**不是黑屏** |
| 4 | 按一下 `T` 再按回来，确认三关都能进 | 切关不崩、不白屏 |
| 5 | **提前在第一关把狗救出来**（走到纸箱处触发） | 二、三关才有忠犬跟随 |
| 6 | 点开右下角声音面板再收起 | 确认不挡 HUD、不挡台词 |
| 7 | 静音系统通知，关掉 QQ/微信弹窗 | 投屏无干扰 |

## 二、3 分钟口播脚本

> 说话节奏：每段控制在 40–45 秒。**宁可少说，不要赶**。
> 每段三列：前面是要按的键，中间是观众该看到什么，后面是嘴里说什么。

### 0:00–0:20 开场（20 秒）

| 按键 | 画面 | 口播 |
|---|---|---|
| 无 | 第一关林荫走廊，主角站在起点 | 「这是一个关于**变老**的游戏。你在年轻时攒下的每一点力量，最后都会被一样一样收走。」 |

**要点**：开场只说这一句，不要介绍技术栈。让画面先说话。

---

### 0:20–1:10 第一关 · 青葱破茧之夏（50 秒）

| 按键 | 画面 | 口播 |
|---|---|---|
| `D` 前进 | 主角跑过走廊 | 「第一关，青年。血 200，蓝 50，跳得很高。」 |
| `Space` 连跳两下 | 主角跳跃、落地 | 「跳跃、冲刺、空中飞踢，全都还在。」 |
| `J` 近战三连 | 打中走廊里的小怪 | 「近战三连，不耗蓝。」 |
| `L` 远程 | 丢出粉笔 | 「远程用粉笔，消耗蓝量。」 |
| `S` 格挡 | 出现格挡动作 | 「按住 `S` 格挡，减伤 70%。」 |
| 走到纸箱 | 忠犬幼犬出现 | 「路上会救一只小狗——**它会陪你走完三段人生**。」 |

**分段小结（这句话必须说）**：「**这一关，你什么都做得到。**」

---

### 1:10–2:00 第二关 · 泥潭钢筋雨夜（50 秒）

| 按键 | 画面 | 口播 |
|---|---|---|
| `T` 切关 | 画面转雨夜办公楼 | 「第二关，中年。同样的操作，但代价变了。」 |
| 停在工位段 2 秒 | 雨、玻璃幕墙、工位、打印机长廊 | 「血从 200 掉到 120。**你开始不经打。**」 |
| `L` 打涡流怪 | 纸飞机被反弹回来 | 「这个怪会把你的远程**反弹**回来——你得改用空中近战。」 |
| `Space`+`J` | 空中飞踢破盾 | 「破盾，只能贴上去打。」 |
| 走到保温杯位置 | 忠犬从幼犬变大黄狗 | 「同一个狗，已经在长大了。」 |

**分段小结**：「**你还是你，但身体已经在跟你讨价还价。**」

> ⚠️ 如果时间紧，第二关可以只走到工位段 + 打一只涡流怪，**不要恋战**。

---

### 2:00–2:40 第三关 · 暮年回响（40 秒）

| 按键 | 画面 | 口播 |
|---|---|---|
| `T` 切关 | 秋园、老宅、暖色 | 「第三关，老年。」 |
| **按 `Space` 一下** | 主角只咳嗽一下，**没有跳起来** | 「按空格——**只会咳嗽一声**。」（停 2 秒，让观众看到） |
| 按 `D` 走两步 | 主角缓慢行走 | 「跳跃，没了。永远没了。」 |
| `L` 连续放 | 记忆碎片自动追踪敌人 | 「但蓝从 50 涨到 200，回蓝 12 点每秒。」 |
| 走过老狗 | 老狗跟随 | 「狗也老了。」 |

**分段小结（这里是全场情绪高点，说慢一点）**：
「**你变得很脆弱，但你也第一次，能不停地打。**」

---

### 2:40–3:00 结局（20 秒）

| 按键 | 画面 | 口播 |
|---|---|---|
| 按剧情走到世界尽头 | 结局演出、暖光 | 「最后一幕。走过去。」 |
| 等黑屏 | 黑屏打字机文本 | （**不说话**，让文字自己走 5 秒） |
| 等落幕卡 | 静态合照 + 制作名单 | 「《见我》。谢谢。」 |

**收尾**：停在这里，**不要再补充技术细节**。评委提问再答。

## 三、现场备注（实测踩出来的，不能删）

**备注 1｜忠犬只有第一关救过才出现**
> 二、三关的忠犬是**继承**关系。干净存档直接按 `T` 切到第二关，狗不会出现——**这是设计，不是 bug**。演示前务必先在第一关走到纸箱救狗。

**备注 2｜渲染路径：默认 WebGL 即可**
> 线上实证（2026-11-08）：默认参数（WebGL）fps 60、134 请求零 404、pageerror 0、D 键位移与 T 切关全部正常。**只有自动化探针（headless Edge）需要 `--disable-webgl`**——headless 环境的 WebGL 上下文丢失是探针环境问题，不是游戏缺陷。真机浏览器默认 WebGL 完全正常；万一现场黑屏，切 Canvas 渲染路径兜底，游戏功能完全一致。

**备注 3｜声音面板**
> 声音面板默认折叠为右下角一个小图标。**若要演示音量调节，提前展开一次**，演示时不要再展开（避免挡台词）。

**备注 4｜不要现场改代码**
> 演示前 `git status` 必须是干净的。任何临时改动都会在投屏时被看出来。

## 四、如果演示时间被压到 90 秒

保留顺序：**开场一句 → 第一关跳两下 → 第三关按空格只咳嗽 → 结局**。
砍掉：第二关全程、所有战斗演示、所有数值口播。

**核心那一击是「空格只剩咳嗽」**——这个对比是全场唯一必须让观众亲眼看到的东西。

## 五、答辩预备（评委可能问，提前想好）

| 可能的问题 | 建议回答方向 |
|---|---|
| 「三关时长多少？」 | 如实答：单关横向路程约 20 秒，含战斗视打法 3–8 分钟；**不吹**（精确计时见 `timing.md` 的实测状态） |
| 「音效素材哪来的？」 | 如实答：素材库导入 + 合成的双轨兜底；授权在确认中，未确认则走合成音 |
| 「为什么老年不能跳？」 | 机制即叙事：跳跃是身体能力，衰老收走它，用「深蓝池」补偿 |
| 「技术上最难的是什么？」 | 三关共用一套 Player 控制器，老年禁跳靠**配置驱动**而非分支硬编码 |
