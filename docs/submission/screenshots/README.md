## 采集与真实性说明

- 六张均为同一会话连续实拍：救狗 → 跨关继承（③④⑤ 中忠犬一直在场）→ 走到终点触发结局。
- ⑦⑧ 为 `58a46cf8` 上的独立补充会话：⑦ 在二关 x=1306 触发 Boss；⑧ 在老年关按住 D 传送到孩子身后（x=1462，距孩子 10px）触发拥抱，截图取触发后 520ms（1200ms 后才会淡出转场）。
- ② 的特写弹窗是 DOM 层，`p.screenshot()` 全页截取，故弹窗与游戏画面同框。
- 采集时驱动侧的升级弹窗自动选「攻击力」、彩蛋弹窗自动空格关闭——这些是演示辅助，不影响画面真实性。
- 与 `docs/demo/` 下早期占位截图的区别：本目录全部为**当前 main 基线的最终版式**（含一关瓦片、二关雨夜、三关秋色与结局卡）。
