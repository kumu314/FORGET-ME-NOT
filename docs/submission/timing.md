## 怎么读这组数字（如实说明）

- 这是**空跑到关底触发线 / 拥抱判定**的时长，不是「完整通关」：不含击破 Boss、升级选择、死亡重试与探索。因此**不能当作 issue #26「8–15 分钟」的验收数字**。
- 「正常打」= 边推进边对**同高地面敌人**按 J 近战，攻击节奏 0.7s/次；空中敌人不追打，Boss 只触发不击杀。全程 0 次死亡。
- 人工真人首次游玩的时长会显著更长（会看剧情、试技能、打 Boss、死亡重试），需在 #26 数值平衡后用真人试玩回填。
- 自动脚本早期受两个非时长因素干扰，均已如实保留在原始记录里：① 二关 x=600 彩蛋弹窗会暂停世界（不按 Space 就停在 x≈597）；② 高频按 J 的攻击硬直会打断推进（60s 内停在 x≈187/317）。
